# ralpix

Autonomous plan execution extension for [pi](https://github.com/earendil-works/pi-coding-agent).

Inspired by [ralphex](https://github.com/umputun/ralphex) — runs markdown plans hands-off, each task in a fresh session to keep the model sharp.

## Quick Start

```bash
# 1. Install the extension (creates ~/.pi/agent/extensions/ralpix/)
# TODO: installation steps after implementation

# 2. Write a plan (docs/plans/feature.md)
# 3. Run it
/ralpix docs/plans/feature.md
```

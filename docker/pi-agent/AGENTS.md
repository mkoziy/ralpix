# Global Pi Instructions

- Prefer `rg` for text search.
- Prefer `rg --files` for file discovery.
- Use `fzf` when an interactive shell step needs narrowing or quick selection.
- Treat project files and user-provided facts as the primary source of truth.
- Treat official docs, package metadata, and explicit verification as stronger than training memory for anything time-sensitive.
- Always verify before making factual claims about versions, release dates, API signatures, model availability, deprecations, or support status.
- Never claim that a package, model, API, or feature "does not exist" unless you verified it.
- If a claim is not verified and could be stale, say that it is based on training and may be outdated.
- If user code or config uses unfamiliar syntax or names, assume it may be valid and modern rather than "correcting" it to an older pattern from memory.

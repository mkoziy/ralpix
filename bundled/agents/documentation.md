# Documentation Agent

Check if documentation needs updates:

## Code Documentation
- Are public APIs documented with JSDoc?
- Are complex functions explained?
- Are there TODO/FIXME/HACK comments that need attention?

## Project Documentation
- Does the README reflect the current state?
- Are there API docs that need updating?
- Is the changelog up to date?

## Configuration Documentation
- Are config options documented with examples?
- Are environment variables documented?

## Missing Documentation
- Identify gaps in documentation
- Suggest what should be added

Report findings with severity: CRITICAL, MAJOR, MINOR.

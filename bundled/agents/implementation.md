# Implementation Agent

Review the code to verify it achieves its stated goals:

## Goal Alignment
- Does the implementation match the plan/requirements?
- Are all required features implemented?
- Are there missing pieces or incomplete work?

## Architecture
- Is the code well-structured and modular?
- Are dependencies properly managed?
- Is the design consistent with the codebase?

## TypeScript Best Practices
- Are types used correctly (no `any` abuse)?
- Are interfaces properly defined?
- Is the code idiomatic TypeScript?

Report findings with severity: CRITICAL, MAJOR, MINOR.
